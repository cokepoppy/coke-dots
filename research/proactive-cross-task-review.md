# 主动跨任务研究：可追溯复刻规格

更新时间：2026-10-11

## 官方资料确认的行为

- OpenAI 将 Dot 描述为可在用户不在线时继续推进任务的个人代理，并可持续复查与工作相关的信息。来源：[Getting started with your dot](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot)。
- 官方任务文档区分了自主唤醒、用户设置的时间或受支持事件触发，以及只读主动研究。主动研究用于从获准信息中发现可能相关的内容，并提出问题或建议；已派发任务则可能获准采取具体行动。来源：[Tasks and memory](https://learn.chatgpt.com/docs/dots/tasks-and-memory)。
- 官方控制文档说明，主动研究不会发送消息、修改应用或控制浏览器/电脑。来源：[Control your dot](https://learn.chatgpt.com/docs/dots/controls)。

公开视频的研究记录见 [research/README.md](README.md) 和 `futurepedia-v1-observations.md`。已检查的视频展示了任务派发、Activity、定时任务、电脑及人工接管等状态；目前找到的公开视频没有展示“完成一项工作后，自动把结果与另一项待办对照并报告冲突”的完整操作序列。因此，下面的具体触发时机和 Activity 徽标属于 Coke Dots 的功能映射，不宣称是逐帧测得的 OpenAI Dots 界面。

## Coke Dots 的复刻映射

1. 用户的一次性顶层任务完成后，系统最多创建一个低优先级、只读的后台复查任务。周期任务、委派子任务、后台复查本身和缺少执行用户归属的任务不触发复查。
2. 复查输入限制为同一工作区的已完成任务结果、最多六条进行中任务摘要、最多十条获准工作区记忆。输入有长度上限，并对常见凭据模式做清理；不读取其他租户、其他会话、连接器或云电脑文件。
3. 没有具体发现时安静结束，不显示已完成空结果卡片，也不创建 Dot 消息或系统通知。发现有证据支持的问题时，在 Activity 标记“Dot 主动研究 · 只读”，显示结果并按用户通知设置通知。
4. 发现只提供给用户决定，不自动更改草稿、页面、应用或外部信息。后续操作必须成为独立的用户授权任务。
5. 全局最多占用一个后台复查槽；普通任务保留四个全局槽和每工作区三个槽。复查优先级为 -1，不能挤占普通工作名额。
6. Pi 在复查中不开放工具。Pi 与 DeepSeek Harness 仍由云电脑中的 Agent 运行时启动；复查工作目录使用 `reviews/<taskId>`，请求不携带电脑控制能力或浏览器工作区路径。服务端只把有界文本上下文传入这次内核请求。

## 演示场景与验收结果

中文演示使用两个独立对话：先让 Dot 起草一份写着“10 月 21 日”的发布公告并保持待审批；再提交“发布时间改为 10 月 22 日”的新决定。Dot 完成新任务后主动比对当前工作，报告日期冲突并询问是否更新草稿。它没有修改或发送内容。

常规 `npm run test:e2e:proactive-demo` 使用隔离临时数据库和确定性本地模型夹具。`npm run test:e2e:proactive-demo:pi` 走真实浏览器与 K3D 租户云电脑：先从本机共享配置只读取得 DeepSeek endpoint/model 和系统钥匙串中的共享凭据，再让 Debian 13 Pod 内的 Pi 运行时发起模型请求。Pod 不把模型凭据写进环境变量或 Kubernetes Secret；服务端只通过已认证的 Agent 运行时请求传入凭据，Pi 通过内存 `AuthStorage` 使用。该模式创建新的临时租户命名空间，验收后仅删除本次租户命名空间。

自动验收检查：任务完成后自动加入复查；复查提示含两处日期证据；原公告仍为等待状态；没有 Scratchpad 或记忆写入；Activity 显示只读徽标及发现内容；页面无运行时错误。测试结果记在该分支的交付记录中。

WebP 由 Chrome 原始 WebM 录屏转换。等待超过 4.75 秒的任务区间会保留开始 1.5 秒和结束 1.25 秒的可读画面，只移除中间静止等待；其他动作保持源播放速度。转换器校验源和输出帧数、转换后动画总时长及完整解码；端到端脚本再用 Chrome 从头到尾按播放时间取样，并要求至少 7 个不同画面。该视频只证明 Coke Dots 当前实现的交互，不证明 OpenAI Dots 的像素级布局或隐藏规则。
