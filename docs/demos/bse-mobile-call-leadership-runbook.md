## 演示目标

让观众看到同一条个人助理流程：手机拨打 Dot → 用中文查真实日程、真实会后 AI 听记和未完成待办 → 用户授权落实会议结论 → Pi 在租户 Debian 云电脑里检查代码、修复、测试、打开页面 → 用户验收 → 创建未合并 PR。整个场景不连接券商、不提交交易委托、不合并或部署代码。

## 推荐会议室布置

1. 手机使用 Chrome 打开公网 `https://codex.cokeagent.com/dots-demo/`，用 Google 主账号登录，使用手机本身的麦克风和扬声器发起 Dot Call。
2. 投影优先显示同一账号下的 Dots 公网页面与 Dot’s computer 浏览器画面，让观众看见 Activity 和云电脑动作。正式采用“手机通话 + 投影桌面”之前，必须现场证明同一用户的任务、通话转写和电脑进度能实时同步；若同步未验证，就镜像手机画面并切换到云电脑窗口，不要临场假设两个页面会自动联动。
3. 手机与投影电脑都只访问公网域名；公网流量经 VPS 隧道转发到 Mac。Dots、DWS、K3D、Pi 和租户 Debian 云电脑都留在 Mac/Mac-local K3D。

### 语音与等待表现

- 每个电话轮次使用自然的一句话，不在同一电话里重复转述同一请求。发起后先快速确认正在查找，再由 Agent 完成较慢工作。
- 分钟级代码任务运行期间，Dot 每 30–45 秒给一次真实进度；不持续静音等待，也不提前念出还没有得到的结果。
- 如果任务还在运行，直接说“代码检查还在进行，我先不报完成”，并让投影继续展示真实 Activity。达到 8 分钟仍未完成则结束现场主流程、保留任务继续运行，不能伪称已修复或已建 PR。
- PR 写入必须在用户对页面和测试验收后进行；不合并、不部署。

## 会前准备与排练

正式会后流程不能提前伪造。会议前只做只读彩排，台词改成“明天的评审会安排是什么？现在有哪些会前资料和准备待办？”，Dot 必须明确会议尚未举行、当前听记是会前语音速记。

会后正式排练/演示前，由 Dots 使用真实账号重新读取：

1. 精确匹配评审日程，核对结束状态、参会时间和时区。
2. 用 DWS Minutes 全范围检索会后新听记，核对唯一记录后读取 `basic,summary,keywords` 和真实行动项；若听记未生成，等它生成，不能拿旧会前速记替代。
3. 读取两条现有待办的实时状态与截止时间；不要重复创建它们，也不要仅凭会前听记猜测完成状态。
4. 将会议结论逐条映射到 `coke-agent-test-stock-app` 当前 `origin/main`。如果 main 已覆盖全部要求，报告“无需代码改动”，不制造 diff/PR；若存在确切缺口，才按最新 `main` 新建 `feature/...`。

## 可重复重置

- 钉钉真实日程、AI 听记和两条待办是只读的稳定输入；每次演示都复用，不重建、不改成虚假的历史会议、不重复发群消息。
- 每次彩排创建新的 Dots 会话/任务；不要重放原来的非幂等 `/api/chat` 请求。
- 按当前 `main` 的实现，每个任务工作区按租户和任务 ID 分开；云电脑 Agent 的工作目录固定为 `/workspace/tasks/<taskId>`，运行时会拒绝与任务 ID 不匹配的路径。复演时创建新的 Dot 任务 ID，就得到新的空任务目录；从最新 `origin/main` 在这个目录内克隆仓库。不要清理整个 PVC，也不需要删除旧任务目录来“重置”。这是代码级隔离证据，公网多轮复演仍须单独验收。
- Chrome 用户配置与任务工作目录不是同一个隔离边界：复演时在云电脑中打开本轮新启动的页面并核对标题、端口和当前代码 SHA；不要为了清空页面而删除浏览器配置。记录本轮启动的开发服务器 PID/端口，只停止本轮自己启动的进程，不按通用名称批量杀进程。
- 保存每轮 `runId`、`taskId`、源 `main` SHA、工作目录、页面端口和服务器 PID，便于复演与排错；历史任务文件保留。只有另行进行存储清理时，才核对任务归属、无活动任务/进程及项目内工件已保存后，清理明确的单个任务目录。
- 重置后从当时最新 `origin/main` 重新克隆/检出，不复用旧 feature 分支或旧代码快照。创建分支前记录 `origin/main` SHA；PR 保持开放后再次演示时复用与同一需求对应的 PR，避免重复造 PR。
- 保留云桌面 Deployment 与 `desktop-data` PVC。只有经核实必须更新 Agent 镜像时，才单独备份、改镜像和回滚点；本演示脚本不要求重建或删除 Pod。
- 测试环境只运行页面验证、单元测试和浏览器 E2E，不配置券商凭据，不连接交易 API，不发委托。

## 正式演示前阻断检查

以下任一项失败时不开始公开演示：

1. 已登录手机 Chrome 的麦克风授权、双向语音、电话悬浮/挂断和中文转写通过真实手机现场测试；设备模拟不算通过。检查当日语音费用，遵守已设定的每日 5 元阈值。
2. Pi 选择器可用且任务确实在 Dot’s computer 的租户 Debian 中执行；云电脑状态 Connected，Chromium 可见，投影画面能持续看到真实动作。
3. 公网 Chrome 能从同一任务读取已结束日程、真实会后 Minutes 摘要/行动项和两条 Todo。此项不得用本机 DWS 命令成功代替公网 Pi E2E。
4. 正在运行的 Mac DWS gateway 版本/工作目录与已安装 LaunchAgent 配置一致，Minutes 路由已注册；仅检查磁盘 plist 或健康接口不算通过。
5. 股票仓库 `origin/main` 与本机基线一致；单测与 Chrome 页面测试通过；该次会议确有未实现需求时才允许出现代码差异与 PR。
6. 记录每个阶段公网 Chrome 截图、任务/Activity、云电脑页面、测试结果和 PR；录屏保持正常可读速度、去掉纯静止等待，输出完整解码的视频到工程目录。不要把文件放在 `/tmp`。
